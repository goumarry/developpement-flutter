# Captures à réaliser avant le rendu (TP 8)

Pas d'accès à l'émulateur ni à la console web depuis l'environnement de
développement de l'assistant : ces captures sont à faire toi-même. Noms exacts
attendus par l'énoncé.

1. **`console-utilisateur-cree.png`** — console Firebase > Authentication >
   Users, avec le compte créé depuis l'application (courriel + date de
   création visibles).
2. **`propagation-temps-reel.png`** — onglet « Orga. » de l'application à côté
   (ou avant/après) de la console Firestore > `events` : modifier le champ
   `title` d'un document dans la console, constater le changement à l'écran
   sans action. Deux captures assemblées ou une capture d'écran partagé.
3. **`refus-regles-securite.png`** — au choix : l'écran « Diagnostic règles /
   index » de l'application après les tests, ou le terminal après
   `scripts/prove_rules.sh`. Le journal texte
   `refus-regles-securite.log` généré par ce script est une preuve
   complémentaire (« capture d'écran ou journal » dans l'énoncé).
4. (utile au README, partie C) capture du message d'erreur d'index manquant,
   avec son lien de création, depuis l'écran « Diagnostic règles / index ».
